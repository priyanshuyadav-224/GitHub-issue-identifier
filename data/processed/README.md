# Processed Datasets Documentation

## Overview
This directory contains deterministically cleaned and validated datasets generated by `scripts/preprocess_dataset.py`.
Two dataset views are maintained to support both supervised learning and unsupervised exploratory discovery:

1. **`github_issues_cleaned.parquet` / `.csv`**: Complete pure issues corpus (N = 3,115). Contains all pure GitHub issues with deduplicated IDs, filtered pull requests, cleaned text, and label status (including unlabeled issues).
2. **`github_issues_supervised.parquet` / `.csv`**: Clean supervised classification dataset (N = 1,459). Strictly filtered to issues with unambiguous ground-truth labels across the 5 target classes.

## Prediction-Time Feature Allowlist vs. Leakage Exclusion Policy

### Allowlist (Available at Submission Time)
- `text`: Combined title and body written by the author.
- `clean_title`: Primary concise summary.
- `clean_body`: Full technical description with code snippets and stack traces.
- `author_association`: Author's repository permission at creation.
- `created_at`: Temporal submission timestamp.
- Derived length statistics: `title_char_len`, `body_char_len`, `text_char_len`, `text_word_count`.

### Excluded Leaky Fields (Unavailable at Prediction Time)
The following attributes accumulate **after** issue submission during triage and resolution:
- `state`: Closed/open resolution outcome.
- `closed_at`, `closed_by`, `state_reason`: Resolution metadata.
- `comments`, `comments_url`: Community discussion and maintainer replies.
- `assignee`, `assignees`: Assigned triage engineer.
- `milestone`: Scheduled release milestone.
- `reactions`: Community thumbs-up and votes.
- `locked`, `active_lock_reason`: Administrative moderation.
- `labels`: Used to construct target ground truth; must never be fed as an input feature.

## Non-Supervised Filtered Issues (Cleaned Corpus, N = 1,656)
- **`UNLABELED` (1,493 issues, 47.93%):** Issues submitted without maintainer tags. Reserved for unsupervised discovery (K-Means/PCA in Milestone 6) and active learning.
- **`UNMAPPED` (129 issues, 4.14%):** Issues tagged with only triage or component labels (`good first issue`, `dataset-viewer`, `vision`) without an issue-type tag.
- **`CONFLICTING` (34 issues, 1.09%):** Issues assigned contradictory labels from multiple classes (e.g. `[bug, enhancement]`).
