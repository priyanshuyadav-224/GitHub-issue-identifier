⚙️ Machine Learning Pipeline Architecture

GitTriage AI uses classical statistical NLP to guarantee sub-millisecond inference latency, zero cloud API dependency, and complete feature explainability.

1. Text Normalization & Token Preservation

Strips markup noise while strictly preserving technical identifiers, code tokens (__iter__), library methods (load_dataset), and version numbers (v1.2.3).

2. High-Dimensional Sublinear TF-IDF

Constructs a 5,000-dimensional sparse representation using unigrams and bigrams. Sublinear term frequency ($\text{TF} = 1 + \log(\text{count})$) prevents long stack traces from dominating feature space.

3. Calibrated Linear Classifier with Cost-Sensitive Weights

Optimizes regularized cross-entropy loss with balanced class weights ($w_k = \frac{N}{K \cdot N_k}$), ensuring robust minority class detection.
