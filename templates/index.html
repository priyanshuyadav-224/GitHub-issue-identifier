Data Ingestion & Feature Engineering Architecture

The pipeline is deterministic, scientifically leak-free, and reproducible:

1. Deduplication & Pull Request Isolation

Deduplicates raw Parquet records based on stable GitHub ID (eliminating 100-row pagination double-fetches). Filters out 4,325 pull requests to isolate pure issue reports.

2. Technical Token Preservation

Preserves technical identifiers (load_dataset), Python methods (__iter__), stack traces, and version numbers while stripping HTML markup noise.

3. Sublinear TF-IDF Feature Representation

Constructs 5,000-dimensional unigram/bigram sparse representation with sublinear term frequency scaling: TF = 1 + log(count).
