🎓 Mid-Term Viva Quick Reference
Top 3 examiner questions and your sharp model answers:
Q: Why filter out Pull Requests?
A: PRs contain diff summaries and code review checklists. Mixing PRs into issue triage causes severe distribution shift and makes classification artificially trivial.
Q: What is Data Leakage in this project?
A: Using post-triage attributes (state: closed, comments, assignee, milestone). Our Feature Allowlist includes ONLY creation-time fields.
Q: How do you handle the 45:1 class imbalance?
A: Accuracy is misleading (majority class gives 52.8%). We mandate Macro-F1 and train using cost-sensitive balanced loss weights.
